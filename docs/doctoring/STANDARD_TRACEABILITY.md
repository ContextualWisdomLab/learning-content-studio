# Standards traceability

Initial content and accessibility profile:

- WCAG 2.2 / ISO/IEC 40500:2025: learner-facing content and Studio UI target WCAG AA.
- ATAG 2.0: the authoring interface must itself be accessible and must help authors create accessible outputs.
- ISO/IEC 24751: learner needs/preferences and alternative-resource matching.
- ISO/IEC 19788-1:2024: canonical learning-resource metadata application profile.
- QTI 3: assessment-content interchange.
- cmi5 Quartz: version-pinned package publisher for LMS-managed launch.
- SCORM 1.2 and SCORM 2004: legacy compatibility publishers only, never the canonical authoring model.
- Common Cartridge: import/export adapter rather than internal source format.

Every publisher must preserve provenance and report semantic loss as an explicit incompatibility rather than degrading content silently.
