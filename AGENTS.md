# Agent development rules

- Keep authoring source, release history, accessibility alternatives, localization, rights, and publication artifacts authoritative here.
- Do not duplicate LMS enrollment/completion, LRS statements, Psychometrics Commons response data, or payment-provider truth.
- Publication is deterministic from an approved immutable content release.
- Unsupported target-format semantics must fail explicitly rather than be silently dropped.
- Authoring UI and generated content target WCAG 2.2 AA; authoring workflows follow ATAG 2.0 principles.
- Use two-or-more-word `snake_case` database object names and third normal form for authoritative relational facts.
- Production statement and branch coverage must be 100%, with complete public API documentation.
